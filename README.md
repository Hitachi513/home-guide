# 家裡網路使用教學

給家人朋友的一步一步教學：用 iPhone 透過 **Shadowrocket** 或 **Tailscale** 連回家裡的網路，以及使用家裡的雲端硬碟。

👉 **直接看教學：https://hitachi513.github.io/home-guide/**

教學裡的名字、數字、QR code 都是範例，不含任何真實的連線資料。

## 多語言 / Languages

繁體中文（原稿 `index.html`）· [English](en/) · [简体中文](zh-CN/) · [日本語](ja/) · [한국어](ko/) · [Español](es/)

第一次打開會依瀏覽器語言自動切換，頁面最上面也可以自己選。
改了中文原稿之後執行 `python3 tools/build.py` 重新產生各語言版本；`--check` 會列出還沒翻譯的段落（翻譯在 `i18n/strings.json`）。
各語言的截圖放在 `img/<語言>/`，沒有的話會用 `img/` 的中文截圖。
